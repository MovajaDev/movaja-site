MOVAJÁ — Protótipo funcional
================================

O que funciona:
- Cadastro e login de conta (dados guardados no localStorage do navegador).
- Perfil simples com MOVAJÁ Pontos de demonstração.
- Busca de hotéis por nome/cidade.
- Favoritos.
- Página/modal de detalhes do hotel.
- Botão "Ir para o site parceiro" com URL FICTÍCIA de teste.
- Layout responsivo para celular e computador.

IMPORTANTE:
- Isto é um protótipo, não um sistema de produção.
- Hotéis, preços e links são ilustrativos.
- O link de afiliado usa example.com e NÃO gera comissão.
- Não usar dados de clientes reais neste protótipo.
- Antes de publicar: backend seguro, banco de dados, autenticação real, LGPD/privacidade, termos de uso, domínio, HTTPS, imagens licenciadas e links oficiais de afiliados.

Como abrir:
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Para publicar, envie o conteúdo para um serviço de hospedagem.
